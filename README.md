* BIT Data Analytics Course Projects

This repository contains tasks, exercises, and solutions developed throughout the BIT Data Analytics course. 
It demonstrates practical applications of data analytics concepts using real-world datasets and commonly used tools.

** Tools and Technologies
- **MySQL** – for database querying and management
- **Power BI** – for data visualization and reporting
- **Python** – for data analytics and scripting

** Databases
- **Sakila** – sample movie rental database
- **AdventureWorks 2019** – sample business database

** Project Overview
By the end of the course, projects will cover a variety of data analytics tasks, including:
- SQL queries and data extraction
- Data cleaning and transformation
- Data visualization and reporting
- Practical exercises applying analytical concepts

This repository reflects the learning process and progression throughout the course, providing examples and solutions for reference and practice.
